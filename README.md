# Atelier — GitHub Pages only

Atelier یک وب‌اپ استاتیک برای دفتر نقاشی شخصی، کشف هنر، تاریخ هنر و شنیدن موسیقی کلاسیک است. این نسخه فقط به GitHub Pages و APIهای عمومی منابع بیرونی تکیه دارد و **هیچ سرور یا هاست دیگری لازم ندارد**.

## انتشار روی GitHub Pages

1. فایل ZIP را استخراج کن.
2. یک مخزن **Public** جدید در GitHub بساز.
3. تمام محتویات پوشه‌ی `atelier-github-pages` را همراه فایل‌ها و پوشه‌ی مخفی `.github` مستقیم در ریشه‌ی مخزن قرار بده؛ `index.html` باید در ریشه باشد.
4. وارد **Settings → Pages** شو و در **Build and deployment → Source**، گزینه‌ی **GitHub Actions** را انتخاب کن.
5. به تب **Actions** برگرد و workflow با نام `Atelier Pages + Art Institute data` را بررسی کن؛ باید داده‌های موزه را همگام و سایت را Deploy کند.
6. وقتی انتشار تمام شد، آدرس نمایش‌داده‌شده در Settings → Pages را باز کن؛ برای مخزن کاربری تو معمولاً `https://cyberhom.github.io/` است.

راهنمای تصویری رسمی: <https://docs.github.com/en/pages/quickstart>

## امکانات

- رابط فارسی و راست‌چین با طراحی موزه‌ای و پس‌زمینه‌ی سبک.
- هشت هنرمند منتخب به ترتیب تاریخی، خط زمانی و جنبش‌های هنری.
- گالری آثار با داده‌های رسمی Art Institute of Chicago که GitHub Actions از API دریافت و به فایل استاتیک تبدیل می‌کند؛ تصاویر از IIIF رسمی موزه لود می‌شوند و Wikimedia Commons فقط منبع جایگزین است.
- Classical Listening Room: جست‌وجو در Internet Archive و پخش فایل‌های صوتی موجود در پلیر داخلی؛ کلید API لازم نیست.
- دفتر آثار، ایده‌ها، قفسه‌ی مطالعه و ثبت تمرین‌ها؛ اطلاعات شخصی در localStorage همین مرورگر نگه داشته می‌شوند.
- امکان پشتیبان‌گیری و بازیابی JSON.

## محدودیت‌ها

GitHub Pages سرویس میزبانی **استاتیک** است و APIهای سمت سرور را اجرا نمی‌کند. برای استفاده از API رسمی Art Institute بدون هاست بیرونی، workflow گیت‌هاب داده‌های عمومی را هنگام Deploy و هر هفته از API دریافت کرده و در `data/artic-artworks.json` ذخیره می‌کند. مرورگر فقط فایل استاتیک را جست‌وجو می‌کند؛ پس مشکل CORS درخواست زنده در مرورگر دور زده می‌شود، بدون اینکه سرور جداگانه‌ای لازم باشد. این محدودیت یعنی جست‌وجو در مجموعه‌ی همگام‌سازی‌شده است، نه جست‌وجوی زنده‌ی نامحدود در تمام دیتابیس. اگر همگام‌سازی داده‌ای دریافت نکند، Commons به‌عنوان جایگزین استفاده می‌شود.

جست‌وجوی موسیقی مستقیماً به APIهای عمومی JSON در Internet Archive متصل است؛ این APIها بر اساس مستندات عمومی قابل درخواست از مرورگر هستند، اما دسترسی شبکه، محدودیت‌های منطقه‌ای یا تغییرات سرویس خارجی همچنان ممکن است اثر بگذارند. همه‌ی قطعه‌ها در آرشیو وجود ندارند و حقوق/مجوز هر فایل باید در صفحه‌ی خودش بررسی شود.

**حریم خصوصی:** داده‌های دفتر شخصی در همان مرورگر ذخیره می‌شوند و خودکار بین دستگاه‌ها همگام نمی‌شوند. برای استفاده از دستگاه دیگر، از خروجی JSON نسخه‌ی پشتیبان بگیر.

## همگام‌سازی API رسمی موزه

فایل `.github/workflows/pages.yml` در هر push به `main` و هر دوشنبه، `scripts/sync-artic-data.mjs` را اجرا می‌کند. این اسکریپت از API رسمی Art Institute آثار دارای تصویر و نشان public domain را دریافت می‌کند، در `data/artic-artworks.json` می‌نویسد و تغییرات داده را در مخزن ثبت می‌کند. سایت سپس با GitHub Pages Actions منتشر می‌شود. برای اجرای workflow، در **Settings → Actions → General** اجازه‌ی نوشتن workflow در مخزن باید فعال باشد و **Settings → Pages → Source** باید روی `GitHub Actions` باشد.

اگر API موزه موقتاً در دسترس نباشد، اسکریپت تا جای ممکن از داده‌ی قبلی استفاده می‌کند و صفحه می‌تواند با Commons جایگزین ادامه دهد.

## پیش‌نمایش محلی

در ویندوز، از ریشه‌ی این پوشه اجرا کن:

```powershell
py -m http.server 8000
```

و بعد <http://localhost:8000> را باز کن. برخلاف نسخه‌های قبلی، این نسخه به `/api/*` نیاز ندارد.
